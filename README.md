# BasicWebAppPHP

This project is a simple web application with a backend written in PHP. It allows users to create an account, login, logout, delete an account and rate some movies that are stored in a database.

The purpose of this project is to let me refresh some basic web development concepts and PHP.

## Technology Used
In order to make this project I used Visual Studio Code for writting the code, Git for source control, Postman for API development and testing and Python to run a local http server.
